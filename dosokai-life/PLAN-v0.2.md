# 同窓会ライフ v0.2 計画書

> 実装済み（絵を除く）。絵は Codex で作る（注文書は `ART-SPEC.md`）。実装で決めた細部は README と events.xlsx の「使い方」シートにある。
> 統計の照合は `node tests/calibrate.js`（統計シートの25項目すべてが幅に入っている）。

v0.1（18〜35歳）を、65歳まで延ばし、結婚・家族・住まい・健康・事故・災害・転機を「現実の統計に合う確率」で入れるための計画。

---

## 1. 方針

1. **確率は統計から決め、表に書く。** 年齢ごとの起きやすさを「確率表」シートに書き、イベントはそれを参照する。統計を差し替えるときにプログラムを触らない。
2. **ゲームの結果が統計と合っているかを、毎回測る。** 「統計」シートに目標値・出典・許容幅を書き、照合スクリプトが「ゲームの値／現実の値」を並べて、外れたものに印を付ける。
3. **統計がないものは、近い統計から組み立てた推計値とし、そう明記する。** 推計値は表の「出典」欄に「推計：根拠」と書く。
4. **主人公の性別は決めない。** 男女で違う統計は、男女の値の間を目標にする。
5. **ゲームとしての調整は、調整だと明記する。** 例：転機の頻度は統計より少し多くする（ご要望）。
6. 前提は v0.1 と同じ：やり直しなし、選択は確率を動かすが結果は決めない。

## 2. 年齢と全体の流れ

| 章 | 年齢 | 同窓会 | 主な出来事 |
|---|---|---|---|
| 1. 青年期 | 18〜35 | 25歳・35歳 | 進路、就職、出会い、結婚、最初の子、最初の転職 |
| 2. 壮年期 | 36〜50 | 50歳 | 住宅購入、子育て、昇進・停滞、親の介護の始まり、転機の山場 |
| 3. 円熟期 | 51〜65 | 65歳（最後の同窓会） | 子の独立、介護、病気、定年（60）と継続雇用（〜65）、定年後の転機 |

- 1年＝1ターンのまま。何も起きない年は1行でまとめて流す（例：「41〜43歳　静かな3年」）。
- 進む速さは5段階：とてもゆっくり／ゆっくり／ふつう／はやい／とてもはやい（決定）。大きな出来事では、どの速さでも止まる。
- 1回のプレイ時間の目安：ふつうで20〜25分、とてもはやいなら5〜8分。
- 同窓会は4回（25・35・50・65）。同級生3人の運命パターンを65歳まで書き足す。
- エンディング（振り返り）は65歳の同窓会のあと。グラフ・年表は65歳まで。
- **死は静かに短く描く（決定）。** 祖父母・親・同級生・パートナーとの別れを、生命表に沿った確率で入れる。いい出来事も悪い出来事も、現実の人生と同じ割合で起きる。仕様書の「死は描かない」はこの決定で置き換える。主人公自身の死も入れる（決定）。タイトル画面に「この人生では、病気や別れ、死も起こります」と一文添える。

## 3. 新しく持つ「暮らしの状態」

5つの数値（お金・健康・手応え・つながり・余白）はそのまま。それとは別に、次の状態を持つ。画面上部に小さく表示する（例：「既婚・子2人・持ち家」）。

| 状態 | 中身 | 条件の書き方の例 |
|---|---|---|
| パートナー | なし／交際中／既婚／離別／再婚。既婚なら配偶者の属性（§4.2） | `パートナー=既婚` `配偶者:働き方=共働き` |
| 子ども | 人数と、それぞれの年齢 | `子ども数>=2` `末子の年齢<6` `子:大学生がいる` |
| 住まい | 実家／賃貸／持ち家（ローンあり・なし）／移住先 | `住まい=持ち家` `ローン=あり` |
| 住んでいる地域 | 地元／都市／移住先。地域ごとの災害の起きやすさ（隠れた運命） | `地域=都市` `地域の災害リスク=高` |
| 健康の履歴 | 持病（がん経験、心の不調、事故の後遺症など） | `持病:がん` |
| 親 | 健在／介護が必要／介護中 | `親=介護中` |

## 4. 結婚と家族

### 4.2 出会いと配偶者のパターン

**出会いのきっかけ**（結婚した夫婦の割合。この割合でくじを引き、どこで出会ったかによって出会う前の出来事の文章を変える）

| きっかけ | 割合 | 出典 |
|---|---|---|
| 職場・仕事 | 21.4％ | 2021年 出生動向基本調査（2018年7月〜2021年6月に結婚） |
| ネット（アプリ・SNS） | 13.6％ | 同上 |

| 学校 | 要確認（前回調査で約1割） | 同上 |
| 街なか・旅先・趣味、見合い・結婚相談所 | 要確認 | 同上 |

- 出会い運（v0.1 の隠れた運命）は、出会いの起きやすさを掛け算で変える役割のまま残す。
- 「職場」は今のキャリアと同じ業界の人になりやすい、「学校」は同級生が絡める、など、きっかけごとに物語を変える。

**配偶者の属性**（結婚のときにくじで決める。一部は隠れた運命として、エンディングで明かす）

| 属性 | 候補と割合 | 出典・根拠 |
|---|---|---|
| 年齢差 | 3歳差以内が約7割。同い年・妻が年上が増えている | 人口動態統計（内閣府資料） |
| 働き方 | 共働き 約7割（1,278万世帯）／片働き 約3割（517万世帯） | 2023年 労働力調査 |
| 実家との距離 | 同じ地域／遠方 | 推計（介護の重なり方に影響） |
| 価値観の相性（隠れ） | 合う／ふつう／ずれがある | ゲームの設計。離婚の起きやすさに影響 |
| 家事・育児の分担（隠れ） | 分け合う／偏る | ゲームの設計。余白の減り方に影響 |

## 5. 住まい

| 目標 | 値 | 出典 |
|---|---|---|
| 持ち家の割合（全体） | 60.9％ | 2023年 住宅・土地統計調査 |
| 家計主の年齢別の持ち家の割合 | 30〜34歳 19.2％／40〜44歳 41.6％／50〜54歳 47.8％ | 同上（家計主ベース。単身を含む） |
| 二人以上の世帯の持ち家の割合 | 30代 66.4％／40代 81.0％ | 2022年 家計調査 |

- 二つの統計の定義が違うので、実装の前に原表で確認し、「単身」「夫婦・家族」で別々の目標にする。
- 住宅購入は「選択」（お金が足りないと灰色）。ローンは毎年のお金を減らし、災害・転職・離婚と組み合わさって効いてくる。
- 一次取得の平均年齢は要確認（国土交通省 住宅市場動向調査）。

## 6. 健康・事故・災害

| 出来事 | 目標 | 出典・根拠 |
|---|---|---|
| がん | 65歳までに診断される人 推計 約1割強。年齢が上がるほど急に増える（60歳男性の10年後 15.7％、女性 10.4％） | 国立がん研究センター |
| 心の不調（うつ病） | 一生のうちに経験する人 6.6％（男3.7％・女9.1％） | 2006年 厚労科研（世界精神保健調査） |
| 脳卒中・心臓の病気 | 50代以降に少しずつ。年齢別の値は要確認 | 循環器疾患の発症登録など |
| 交通事故でけがをする | 1年に約0.28％（負傷者 34万3,756人÷人口）。18〜65歳の間に一度でもけがをする人は約8人に1人（推計） | 2024年 警察庁 |
| 重いけが | 1年に約0.02％前後（要確認） | 警察庁（重傷者数） |
| 住んでいる地域が大きな災害に見舞われる | 地域の災害リスク（隠れた運命）で変える。太平洋側などは30年以内に震度6弱以上が26％以上 | 地震調査研究推進本部 全国地震動予測地図 |
| 自宅が被害を受ける | 推計 一生で数％。大きな地震の年に集中する（例：能登半島地震 全壊 約8,500棟、半壊・一部破損 約11.5万棟） | 防災白書・消防白書。年平均は災害年報で要確認 |
| 親の介護 | 働きながら介護する人 365万人。介護を理由に仕事を辞める人 年10.6万人 | 2022年 就業構造基本調査 |

- 健康の数値が低いと病気が起きやすくなる、体質（隠れた運命）で倍率が変わる、という v0.1 の仕組みは残す。
- 事故・災害・病気は「運命」。選べるのは向き合い方だけ（休む、続ける、住まいを移す、など）。
- 主人公自身の死も入れる（決定）。確率は生命表（65歳までに 男10.4％・女5.6％）に合わせる。

## 8. 転機（思い切った転身）

ご要望どおり、統計の推計（50歳までに10人に1人前後）より少し多くする。

- **目標：65歳までに約5人に1人**が、人生の向きを大きく変える選択をする。統計より多めにしているのは、ゲームとしての調整。
- 「転機の誘い」は、確率表の年率でやってくる。受けるかどうかは**選択**。お金・家族・健康で選べない選択肢は灰色にする。

| 転機 | 起きやすい年齢 | 根拠にする統計 |
|---|---|---|
| 会社を辞めて、キャンピングカーで日本一周 | 30代、50代以降、定年後に山 | キャンピングカー保有 約16.5万台（2024年）。購入者の約8割が40代以上 |
| 地方へ移住（地域おこし協力隊など） | 20〜30代が約6割 | 協力隊 7,910人（2024年度）。任期後 約7割が定住 |
| 脱サラして店・会社を開く | 40代前半が中心 | 開業時の平均年齢 43.5歳。開業直前は勤め人が約8割 |
| 学び直し・留学 | 30〜40代 | 要確認 |
| 海外で働く・暮らす | 20〜30代 | 要確認 |
| 実家の家業・畑を継ぐ | 40〜50代 | 要確認（同級生の拓海Cとつなげられる） |

- 転機を選ぶと、数値は大きく揺れる（お金は下がりやすく、余白・手応えは上がりやすい）。その後に「うまくいった／戻った」の運命が続く。
- 振り返りに「転機」のラベルを足す（TOP5の【選択】【運命】に加えて）。

## 8.5 人生のくじ（低確率イベント）

宝くじ、エベレスト登頂、裁判員、双子、アイドルデビューなど、めったに起きない出来事を現実の確率で入れる。122種類の案と確率・根拠は `RARE-EVENTS-v0.2.md` にまとめた。

- 毎年、通常の出来事とは別に「くじ」を引く。起きたら、レア度（★1〜★5）と「日本では約◯人に1人」を添えて見せる。
- 段階を踏むもの（エベレストなど）は連鎖させ、最後の確率が現実に合うようにする。
- 振り返りに「この人生で引いたくじ」を出す。ブラウザに「人生図鑑」を残し、遊ぶたびに集まるようにする。
- 表には「くじ」シートとして入れる（列：出来事／年齢／条件／年率／レア度／確度／根拠）。

## 10. 決まったことと、決めていただきたいこと
