# 同窓会ライフ（仮題）試作品 v0.2

`SPEC.md` と `events.xlsx` をもとにした、サーバー不要のブラウザゲームです。
v0.2 で、18歳から65歳までの人生になりました。結婚・子ども・住まい・病気・事故・災害・介護・死・転機を、現実の統計に合う確率で入れています。
設計は `PLAN-v0.2.md`、人生のくじの一覧と根拠は `RARE-EVENTS-v0.2.md` にあります。

## 遊び方
`index.html` をブラウザで開くだけです（ダブルクリックで動きます）。スマホ縦向きの画面を想定しています。

- 運命の番号（6桁）を入れると、同じ運命で遊べます。`index.html?seed=123456` か `index.html#123456` で指定できます
- 進む速さは5段階（とてもゆっくり〜とてもはやい）。大きな出来事では止まります
- タイトル画面の「人生図鑑」で、これまでに引いた人生のくじが見られます（記録はそのブラウザにだけ残ります）
- `?debug=1` を付けると確認用パネルが出ます（数値を変える、指定した出来事を次に起こす）

## イベントを足す・直す
1. `data/events.xlsx` を編集する（「使い方」シートに書き方があります）
2. `python3 tools/convert.py` を実行する（openpyxl が必要です：`pip install openpyxl`）
3. ブラウザを再読み込みする

プログラムを触る必要はありません。書式が読めない行があっても、ゲームは止まらずに、画面右下とコンソールに「E0xx の条件が読めません」と出ます。

### 表のシート
| シート | 中身 |
|---|---|
| イベント | 毎年起きる出来事（選択／運命／一行）。確率は数値か「表:名前」 |
| くじ | 人生のくじ（めったにない出来事）122種類。レア度・一生で・確度・根拠つき |
| 確率表 | 年齢などごとの起きやすさ（年率）と出典。生命表、未婚率、出産、がん、事故、災害など |
| 統計 | 照合の目標（現実の値・許容幅・出典） |
| 配偶者 | 出会いのきっかけ・年齢差・働き方・相性・分担の候補と割合 |
| 同窓会 | 25・35・50・65歳の同窓会の文章 |
| 同級生 | 健太・美咲・拓海の運命パターン（65歳まで）と亡くなりやすさ |
| キャリア | 仕事ごとの毎年の変化・会社の運命・区分（会社員・公務員など）。最初の仕事は16種類で、実際の就職先の割合（大卒・高卒別）・合格率・景気の影響・会社の例もここに書く |
| 人物 | 立ち絵とカットインに使う絵のファイル名の形 |

## 絵（立ち絵・カットイン）
絵がなくても動きます。絵の注文書は `ART-SPEC.md` です。
絵を `assets/chara/` に置いて `python3 tools/convert.py` を実行すると、表の「演出」列に書いた場面で出るようになります。

## ファイル
| ファイル | 中身 |
|---|---|
| `index.html` / `style.css` | 画面 |
| `js/rng.js` | シード付き乱数（生まれ・隠れた運命・景気と、毎年のサイコロを別々の乱数の流れにする） |
| `js/rules.js` | 条件・効果・確率・演出などの書式を読む部分（ひとまとめ） |
| `js/engine.js` | 1年の流れ、合否、景気、家族、生死、同窓会、振り返りの集計。仮値は先頭の `CONFIG` |
| `js/ui.js` | 表示、自動進行、演出、人生図鑑 |
| `data/events.xlsx` | 元の表（ここを編集する） |
| `data/events.json` / `data/events.js` | 変換で作るファイル（手で編集しない） |
| `tools/convert.py` | 変換スクリプト |
| `tests/` | 確認用のスクリプト |

## 確認
```
node tests/run.js          # SPEC 17章の1〜6をブラウザなしで確認（2000通りの人生を最後まで通す）
node tests/calibrate.js    # ゲームの値を「統計」シートの現実の値と比べる。人生のくじの出方も比べる
node tests/browser.js      # 実際のブラウザで確認し、画面写真を tests/screenshots/ に保存（Playwright が必要）
node tests/balance.js      # 人生の形などの偏りを測る（調整用）
```
人生の形は「ふつうの人生と比べて、いちばんよく伸びた数値」で決めています。表や確率を大きく変えたら、
`tests/balance.js` が最後に出す平均と散らばりで `js/engine.js` の `CONFIG.shapeBaseline` を書き換えてください。
