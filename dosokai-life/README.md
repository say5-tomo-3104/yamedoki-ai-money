# 同窓会ライフ（仮題）試作品 v0.1

`SPEC.md` と `events.xlsx` をもとにした、サーバー不要のブラウザゲームです。

## 遊び方
`index.html` をブラウザで開くだけです（ダブルクリックで動きます）。スマホ縦向きの画面を想定しています。

- 運命の番号（6桁）を入れると、同じ運命で遊べます。`index.html?seed=123456` でも指定できます
- `?debug=1` を付けると確認用パネルが出ます（数値を変える、指定した出来事を次に起こす）

## イベントを足す・直す
1. `data/events.xlsx` を編集する（「使い方」シートに書き方があります）
2. `python3 tools/convert.py` を実行する（openpyxl が必要です：`pip install openpyxl`）
3. ブラウザを再読み込みする

プログラムを触る必要はありません。書式が読めない行があっても、ゲームは止まらずに、画面右下とコンソールに「E0xx の条件が読めません」と出ます。

### v0.1 で表に足した書き方
- 列「選択肢1の条件」〜「選択肢3の条件」：満たさないとき、その選択肢は灰色になる（例：`お金>=40`）
- 列「確率の補正」：`条件→0.8` で置き換え、`条件→×1.5` で掛け算。複数は「／」で区切る
- 本文と選択肢の出し分け：`〔条件〕ここだけ出す〔/〕`、`〔条件〕A〔それ以外〕B〔/〕`
- ゲームが用意する条件：`フラグ:就活の年`（大学入学＋3年。浪人・休学で1年ずれ、22歳まで）、`前年の景気=大不況` など

## ファイル
| ファイル | 中身 |
|---|---|
| `index.html` / `style.css` | 画面 |
| `js/rng.js` | シード付き乱数（生まれ・隠れた運命・景気と、毎年のサイコロを別々の乱数の流れにする） |
| `js/rules.js` | 条件・効果の書式を読む部分（ひとまとめ） |
| `js/engine.js` | 1年の流れ、合否、景気、会社の運命、同窓会、振り返りの集計。確率などの仮値は先頭の `CONFIG` |
| `js/ui.js` | 表示と自動進行 |
| `data/events.xlsx` | 元の表（ここを編集する） |
| `data/events.json` / `data/events.js` | 変換で作るファイル（手で編集しない） |
| `tools/convert.py` | 変換スクリプト |
| `tests/` | SPEC 17章の確認 |

## 確認（SPEC 17章）
```
node tests/run.js        # 1〜6 をブラウザなしで確認（あわせて2000通りの人生を最後まで通す）
node tests/browser.js    # 3と6を実際のブラウザで確認し、画面写真を tests/screenshots/ に保存
```
`tests/browser.js` には Playwright が必要です。

## 遊びの偏りを測る（調整用）
```
node tests/balance.js 5000   # 5000人分の人生をランダムな選び方で進めて集計する
```
人生の形の出方、就職の結果、35歳のキャリア、一行の出来事の重なり、運命の割合などを出します。
人生の形は「ふつうの人生と比べて、いちばんよく伸びた数値」で決めています。表や確率を変えたら、
このスクリプトが最後に出す平均と散らばりで `js/engine.js` の `CONFIG.shapeBaseline` を書き換えてください。
