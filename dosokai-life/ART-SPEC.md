# 絵の注文書（Codex 向け）v0.2

同窓会ライフの立ち絵（胸から上）とカットインに使う絵の一覧です。
絵がなくてもゲームは動きます（絵がない場面では何も出さず、カットインは帯と文字だけで出ます）。
絵を足すときは、プログラムを触る必要はありません。

## 置き方
1. 下の一覧のファイル名で、`dosokai-life/assets/chara/` に置く
2. `python3 tools/convert.py` を実行する（assets フォルダの絵の一覧が data/events.js に入る）
3. ブラウザを再読み込みする

公開ページに入れるときは、絵も一緒に公開します（Claude に頼んでください）。

## 絵の決まり
| 項目 | 決まり |
|---|---|
| 構図 | 胸から上（バストアップ）。頭の上に少し余白 |
| 大きさ | 縦長 600×800 ピクセル（3:4） |
| 背景 | 透明 |
| 形式 | WebP（1枚 60KB 以下が目安）。PNG でも動くが、ファイル名の拡張子は人物シートの「ファイル名の形」に合わせる |
| 向き | 正面か、やや斜め。画面の左にも右にも出るので、左右どちらを向いていても使える絵が望ましい |
| 雰囲気 | 落ち着いた色合い。地方都市の、ふつうの人たち。線は細め |
| 年代 | 同じ人物の 18・25・35・50・65 歳。年代ごとに少しずつ年を取る（白髪、しわ、服装の変化） |
| 主人公とパートナー | 性別を決めていない。シルエット、後ろ姿、輪郭だけ、性別のわかりにくい描き方など、どちらにも見える表現にする |
| 注意 | 既存の作品（逆転裁判など）の人物や絵を使わない。演出のやり方をまねるのは問題ない |

## 表情（ファイル名の英字）

| 表情 | ファイル名に入る文字 |
|---|---|
| ふつう | normal |
| 笑顔 | smile |
| 驚き | surprise |
| 悲しみ | sad |
| 怒り | angry |
| 照れ | shy |
| 真剣 | serious |

いちばん大事なのは「ふつう（normal）」です。ほかの表情がないとき、画面は「ふつう」の絵を代わりに使います。
まずは各人物・各年代の「ふつう」から作るのがおすすめです。
