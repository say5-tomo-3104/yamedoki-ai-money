# やめどきAI Money — 15秒モーショングラフィック

`out/yamedoki-15s.mp4`（1080×1920 / 30fps / 15.0秒 / H.264 + AAC）

参考動画（音ハメのキネティック・タイポグラフィ）を ffmpeg で 0.5 秒ごとに切り出して観察し、
**動き方・テンポ・場面の切り替え方の「考え方」だけ** を借りて、中身（文言・数字・構成・音）はこのアプリ用に作り直しています。

## 参考動画から読み取ったルール

| 観点 | 参考動画で起きていたこと | この動画での使い方 |
| --- | --- | --- |
| テンポ | 約 128 BPM。カットの間隔が 0.467 秒（= 1 拍）でそろっている | 128.57 BPM（30fps でちょうど 14 フレーム = 1 拍）。8 小節 = 32 拍 = 15 秒 |
| 1 拍 1 アクション | 拍ごとに数字が進む／語が増える／背景色が変わる | すべての拍に何かを置く（数字・語・図形・ブロック・背景リングの回転） |
| 切り替え | ハードカットと、右からの 2〜3 フレームのワイプだけ。クロスフェードなし | 同上。ワイプ中は旧シーンと新シーンを左右に並べて描く |
| 動き | 一瞬で着地してピタッと止まり、次の拍を待つ。オーバーシュートは小さい | 閉形式スプリング（減衰振動のステップ応答）で 0.1〜0.15 秒で着地 |
| 文字 | 見出しは 1 語ずつ積み上がり、最新の語だけアクセント色 | `headline()` で同じ挙動 |
| 数字 | 大きな数字がオドメーターのように上下に入れ替わる／カウントダウン＋ブロック | 1→10 件、1→12 ヶ月のカウント＋ブロック |
| 強調 | 大きく入ってきて縮んで止まる（スラム）＋背景フラッシュ＋残像 | ¥18,710 / ¥224,520 / 卒業。/ やめどき |
| 緩急 | 直前に「無音」の 1 拍を置いてからドロップ | 8 拍目を無音（rest）、9 拍目「月額」、10 拍目でドロップ |
| 色 | 赤・黄・青・クリーム・黒の 5 色だけ | 同じ考え方の 5 色パレット |
| データ感 | 実測値（キック位置・秒数）を小さな等幅タグで添える | 実測したキック位置・金額・スコアをタグで表示 |
| 構成 | 「数える → 溜め → ドロップ → 数える → 判定 → 締めの一言 → タイトル」 | 下の絵コンテ |

## 作り方

```
motion/
  audio.py      numpy だけで曲を合成 → audio.wav、書き出した音を解析してキック実測位置を beatmap.json に保存
  beatmap.json  BPM・拍の長さ・キック実測位置・サンプルデータの集計
  index.html    canvas 1080×1920（フォントは @fontsource）
  scene.js      seek(t) — すべての見た目を時刻 t から計算（状態なし・タイマーなし）
  render.mjs    ローカル HTTP サーバー + Playwright で 450 フレーム撮影 → ffmpeg で mp4
  out/          完成動画
```

```bash
cd motion
npm install          # フォント（@fontsource/noto-sans-jp, anton, jetbrains-mono）
npm run build        # = python3 audio.py && node render.mjs
```

- 必要なもの: Python 3 + numpy、Node.js、ffmpeg、Playwright（Chromium）
- 確認用の静止画だけ出す: `node render.mjs --frames 0,140,252,420` → `work/yamedoki_*.png`
- ブラウザでプレビュー: `python3 -m http.server` を `motion/` で起動して `index.html` を開き、クリックで再生（音と同期）

# 歌詞版 — Something Great (Sky)（3分14秒）

- `out/something-great.mp4`（縦 1080×1920 / 30fps / 193.9秒 / 曲の音そのまま）
- `out/something-great-wide.mp4`（横 1920×1080 / 同じ内容）

元のリリック動画（横長・青いリングの 3D 背景）を、上の 15 秒版と同じ考え方（拍で動く・語が積み上がる・スラム・ワイプ・5 色）に置き換えたもの。

## 曲の解析（`lyric/analyze.py`）

| 手順 | 中身 |
| --- | --- |
| 拍の追跡 | キック帯域（35〜110Hz）の立ち上がりを 1ms 単位で計算し、動的計画法で 1 拍ずつ追う。この曲はテンポが 134〜138 BPM で揺れているので、固定グリッドではなく実測の拍（438 拍）を使う |
| 拍の位置合わせ | 各拍をキックの山の立ち上がりに寄せ、全帯域のオンセットと区間ごとに照合して補正（実行時に `onset check` で全区間 −50ms ± 20ms ＝ 立ち上がりに一致していることを表示） |
| 小節の頭 | 拍ごとの和音の変化量が最も大きい位相（確信度は低め。HUD の小節表示にだけ使用） |
| 歌詞 | 元動画を ffmpeg でフレーム差分 → 表示が変わった 115 か所の静止画から読み取った歌詞と秒数を `lyric/lyrics.json` に記録。拍番号に変換して 16 分音符に寄せる |

## 見せ方（`lyric/scene.js`）

| テンプレート | 使う歌詞 | 動き |
| --- | --- | --- |
| `count` | MINUTES TO GO 3 / 2 / 1 | 巨大な数字 + 残り時間 + 拍ごとに埋まるブロック |
| `stack` | READY TO SHINE / ON ITS WAY など | 語が積み上がり、最新の語だけアクセント色 |
| `hero` | LIGHT / MAGIC / GREAT / SPARKLE / STEP / STAR / READY | 前置き → 主役の語をスラム（フラッシュ）→ 後置き。主役ごとに添える図形が変わる（光線・イコライザー・矢印・成長する円・階段・星） |
| `two` | サビの READY TO SHINE / READY TO GLOW | 前半は左寄せ、後半は右寄せのアクセント色 |
| `giant` | TAKE A BREATH… / LET YOUR DREAMS… / YOU DON'T HAVE… | 1 語ずつ画面いっぱいに。上に歌詞全体の行 |
| `boxes` | SOMETHING WONDERFUL… / HAND IN HAND… など | 1 語ずつ箱に入って並ぶ。箱には実測の秒数 |
| `pair` | SIDE BY SIDE | 左の SIDE と右の SIDE |
| `countdown` → `zero` → `title` | FOUR THREE TWO ONE → 0 ALL SET LET'S GO | 1 語ごとに背景色が変わる → 最後にタイトル |

8 拍以上続くフレーズでは、下段の図形が 1 拍ごとに 1 つずつ増える（どの拍にも必ず動きがある）。

## 作り直し方

```bash
cd motion
python3 lyric/analyze.py <曲の mp4 か wav>    # → lyric/song.wav, lyric/data.json
node render.mjs --project lyric               # → out/something-great.mp4（縦）
node render.mjs --project lyric-wide          # → out/something-great-wide.mp4（横）
```

横長は同じ `scene.js` を `?aspect=wide` で開いたもの。座標は `scene.js` 冒頭のレイアウト表 `L`（縦・横の 2 通り）にまとめてあり、
横では箱を 3 列、サビを 2 行、カウントは数字を左・残り時間を右、0 は左に数字・右に ALL SET / LET'S GO に組み替えている。

- 歌詞・見せ方・背景色を変えるときは `lyric/lyrics.json` を編集して上の 2 行を再実行
- 一部分だけ確認: `node render.mjs --project lyric --from 1800 --to 2400`（フレーム番号）
- 曲の音（`lyric/song.wav`）はリポジトリに入れていない
