# brand-assets — ブランド素材フォルダ

**Claude Code はデザイン作業のたびに、このフォルダの中身を必ず参照します**
（ルールは `CLAUDE.md` の 1-1 に定義）。

文章でルールを書くだけでなく、**実物の画像を置く**ことで、
Claude が色・フォント・トーンを直接読み取れるようになります。
ここが仕上がりを一番左右する場所です。

## 何を入れるか

| ファイル名の例 | 中身 |
|---|---|
| `logo.png` / `logo.svg` | サイトロゴ |
| `icon.png` | アプリアイコン（💸 のブランドアイコン） |
| `character-*.png` | ブログで使うキャラクター画像（あれば全ポーズ分） |
| `past-lp-*.png` | 過去に作った LP・バナー・アイキャッチのスクリーンショット |
| `reference-*.png` | Awwwards / Dribbble で見つけた参考サイトのスクリーンショット |
| `font-sample.png` | 使いたい書体の見本 |

## 増やすほど精度が上がります

素材が2〜3点しかない状態と、10点以上ある状態では、出力の質がはっきり変わります。
「これはブランドっぽいな」と思う画像を見つけたら、その都度ここに足してください。

## 参考サイトの渡し方

参考画像を入れただけでは伝わりません。**どこを参考にしてほしいか**を1文添えてください。

```
brand-assets/reference-01.png のような雰囲気で作ってください。
特に余白の取り方と、見出しの文字サイズのメリハリを参考にしてください。
```

## 注意

- 他社のロゴや、権利が不明な画像を「自分のブランド素材」として置かないこと。
  参考サイトのスクリーンショットは `reference-` を付けて、参考であることが分かるようにする。
- 大きすぎる画像（5MB 超）は入れない。リポジトリが重くなります。
