# seo-checklist.md — 公開前チェックリスト

記事を公開する直前に、上から順に確認します。
1つでも × があれば公開しない。**これを守るだけで、他の個人ブログと差がつきます。**

---

## 1. 記事単体のチェック

### タイトル・メタ情報
- [ ] タイトルは 32文字以内で、主要キーワードが前半にある
- [ ] メタディスクリプションを 120文字前後で手動入力した（自動生成に任せない）
- [ ] メタディスクリプションに、記事を読むと何が分かるかが書いてある
- [ ] スラッグ（URL）が英数字・ハイフン区切りになっている
- [ ] カテゴリを **1つだけ** 選んだ（複数選択しない）
- [ ] タグはサービス名・金額帯のみで、3つ以内

### 本文
- [ ] h2 が 3〜5個で、上から読むと要約になる
- [ ] h1（タイトル）は1つだけ。本文中に h1 を使っていない
- [ ] 見出しの階層が飛んでいない（h2 → h4 になっていない）
- [ ] 1段落が3行以内
- [ ] 金額に月額と年額が併記されている
- [ ] 表または箇条書きが h2 ごとに1つ以上ある
- [ ] `brand.md` の NG 表現が入っていない
- [ ] 誤字脱字を確認した（音読するのが確実）

### 画像
- [ ] アイキャッチが 1200×630px で、ブランドの型に沿っている
- [ ] すべての画像に alt テキストがある
- [ ] 画像ファイル名が英数字
- [ ] WebP に変換済み、1枚 200KB 以下
- [ ] 画像に width / height が設定されている（レイアウトのガタつき防止）

### リンク
- [ ] ピラー記事（またはクラスター記事）への内部リンクがある
- [ ] 記事末に「次に読む記事」が 1〜2本ある
- [ ] 外部リンクは公式サイトのみ。`target="_blank"` と `rel="noopener"` を設定
- [ ] リンク切れがない
- [ ] アフィリエイトリンクがある場合、`rel="sponsored"` を設定し、
      記事冒頭または末尾に PR 表記を入れた

### 正確性（このサイトでは最重要）
- [ ] 記載した料金を **公式サイトで確認** した
- [ ] 「※料金は◯年◯月時点の税込価格です」を記載した
- [ ] 解約手順を公式のヘルプページで確認した
- [ ] 投資・金融商品の推奨と受け取られる表現がない

---

## 2. 表示の確認（3サイズ）

`docs/design-workflow.md` の秘訣3の手順で、3サイズ分のスクリーンショットを撮って確認します。

```bash
node scripts/screenshot.mjs https://自分のブログURL/記事のURL
```

- [ ] `screenshots/` の desktop / tablet / mobile の3枚を目視で確認した
- [ ] 3枚を Claude Code に見せて、崩れ・余白・文字サイズの問題を洗い出した
- [ ] 指摘された箇所を修正し、**撮り直して**問題が消えたことを確認した
- [ ] 実機（またはブラウザの開発者ツール）でも表示を確認した
- [ ] 横スクロールが発生していない（特に表）
- [ ] 表が3列を超えていない。超える場合は横スクロール可能にした
- [ ] 目次が長すぎない（h3 まで、20項目以内）
- [ ] ボタン・リンクが指で押せる大きさ（高さ 44px 以上）

---

## 3. サイト全体の設定（初回のみ・その後は月1回確認）

- [ ] Google Search Console に登録し、サイトマップを送信した
- [ ] Google Analytics（GA4）を設置した
- [ ] XML サイトマップが生成されている
- [ ] `robots.txt` が正しい（誤って `Disallow: /` になっていないか）
- [ ] 「検索エンジンでの表示」設定で、インデックスを許可している
      （WordPress 設定 → 表示設定 → 「検索エンジンがサイトをインデックスしないように」のチェックが**外れている**）
- [ ] SSL（https）が有効で、http からリダイレクトされる
- [ ] favicon（💸 のブランドアイコン）を設定した
- [ ] OGP 画像がデフォルトで設定されている
- [ ] 404 ページがカスタマイズされ、トップと人気記事への導線がある
- [ ] 固定ページ5点（About / 運営者情報 / お問い合わせ / プライバシーポリシー / 免責事項）が公開済み
- [ ] フッターにその5ページへのリンクがある

---

## 4. 表示速度

- [ ] PageSpeed Insights のモバイルスコアが 50 以上（80 以上が理想）
- [ ] プラグインが10個以内
- [ ] 使っていないテーマ・プラグインを削除した
- [ ] Web フォントを読み込みすぎていない（1〜2ファミリーまで）

---

## 5. 公開後にやること

- [ ] Search Console の URL 検査から **インデックス登録をリクエスト**
- [ ] SNS で共有し、OGP 画像が正しく表示されるか確認
- [ ] 関連する既存記事から、この新記事へのリンクを追加した
      （← ここを忘れる人が多い。**新記事への内部リンクは自分で作る**）
- [ ] 1か月後に順位と滞在時間を確認し、リライト対象リストに入れる

---

## 6. 月次メンテナンス

毎月1回、次を確認する：

1. Search Console で「表示回数は多いがクリック率が低い」記事を3本抽出 → タイトルとメタディスクリプションを書き直す
2. 掲載サービスの料金改定がないか確認（特に動画配信・AI 系は改定が多い）
3. リンク切れチェック
4. WordPress 本体・テーマ・プラグインの更新（更新前にバックアップ）
5. 3か月以上更新していない上位記事に、最新情報を追記して更新日を新しくする
