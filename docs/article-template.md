# article-template.md — 記事の型と執筆ルール

すべての記事はこの型に沿って書きます。
型が同じだと、読者は「読み方」を覚えられ、サイト全体がプロっぽく見えます。

---

## 1. 記事の基本構造

```
① タイトル（32文字以内）
② アイキャッチ画像
③ リード文（3〜4行）— 結論の予告と、読者の悩みの言語化
④ 目次（自動生成）
⑤ 本文（h2 を 3〜5個）
⑥ まとめ（3行 + 箇条書き3点）
⑦ 次に読む記事（1〜2本）
⑧ アプリへの導線
```

### ③ リード文のテンプレ

```
「（読者の状況）」——そんな方は多いのではないでしょうか。

この記事では、（この記事で分かること）を（数字）つの視点で整理します。
読み終わるころには、（読者が得られる状態）になっているはずです。
```

**リードに自分語りを入れない。** 読者の話から始めること。

### ⑥ まとめのテンプレ

```
## まとめ

（本文の結論を2〜3行で）

- （要点1）
- （要点2）
- （要点3）

迷ったら、まず「先月ちゃんと使ったか」だけ思い出してみてください。
```

---

## 2. 見出しのルール

- **h2 は 3〜5個。** それ以下は内容が薄く、それ以上は分割すべき記事です。
- h2 だけを上から読んで、記事の要約になっているか確認する。
- h2 に「はじめに」「おわりに」を使わない。中身を書く。
- 見出しは体言止めより **問いか結論**：
  - × 「Netflix の料金について」
  - ○ 「Netflix は月1,590円。元が取れるのは月4本以上」
- h4 以下は使わない。必要になったら構成を見直す。

---

## 3. 本文の書き方

| ルール | 理由 |
|---|---|
| 1段落 3行まで | スマホで読まれるため |
| 1文 60文字まで | 途中で意味を見失わせない |
| 漢字とひらがなの比率は 3:7 | ひらいた方がやさしく読める |
| 数字は必ず「月額」と「年額」を併記 | 判断の材料になるのは年額 |
| 表・箇条書きを h2 ごとに最低1つ | 流し読みでも要点が残る |

### ひらく言葉（統一）
`事 → こと` / `時 → とき` / `為 → ため` / `出来る → できる` / `無い → ない` /
`下さい → ください` / `様々 → さまざま`

### 金額の書き方
- 必ず税込。`月1,590円（年間19,080円）` の形式。
- 三桁区切りのカンマを入れる。
- 記事末に確認日を書く：`※料金は2026年8月時点の税込価格です。`

## 4. 記事タイプ別の型

### A. 判断基準の記事（カテゴリ: review）

```
h2 なぜ「なんとなく払い」は起きるのか
h2 やめどきを決める3つの質問
h2 それでも迷うときの考え方
h2 まとめ
```

### B. サービス別ガイド（カテゴリ: services）

**この型は固定。全サービスで同じ順番にすること。**

```
h2 ◯◯の料金プラン（表で全プラン）
h2 元が取れる条件（月に何回使えば1回あたり◯円か）
h2 見直しを考えたほうがいいケース
h2 解約する場合の手順と注意点
h2 代わりになる選択肢
h2 まとめ
```

「元が取れる条件」は必ず**1回あたりの単価**まで計算する。
例：`月1,590円 ÷ 月4本 = 1本あたり約398円。レンタルより安い。`

### C. AI とお金（カテゴリ: ai-money）

```
h2 いま契約している AI ツールを並べてみる
h2 用途が重なっているのはどれか
h2 1つに絞るなら、判断はここで分かれる
h2 まとめ
```

### D. アプリの使い方（カテゴリ: app）

```
h2 何ができる機能か
h2 使い方（スクリーンショット付きで3ステップ）
h2 こう読むと判断しやすい
h2 まとめ
```

---

## 5. タイトルの作り方

**型：`【数字 or 状況】+ 具体的な対象 + 得られる結果`（32文字以内）**

| ○ 良い例 | × 悪い例 |
|---|---|
| サブスクのやめどきを決める3つの質問 | サブスクについて考えてみた |
| U-NEXTは高い？月2,189円の元を取る条件 | U-NEXTのメリット・デメリット |
| ChatGPTとClaude、両方契約する意味はあるか | AIツール徹底比較！ |

- 記事の主要キーワードを**タイトルの前半**に置く。
- 煽らない（`brand.md` の NG 表現を参照）。
- 「まとめ」「徹底解説」「完全版」は安易に使わない。中身が伴うときだけ。

---

## 6. 画像のルール

- アイキャッチ：1200×630px、`brand.md` のルールに従う。
- 本文中の画像：h2 ごとに最大1枚。装飾目的の画像は入れない。
- スクリーンショットは角丸 14px、影は `0 8px 16px rgba(56,189,248,0.15)`。
- alt テキストは必ず記入。「画像」ではなく内容を書く。
- ファイル名は英数字（`u-next-price-table.png`）。日本語ファイル名は禁止。
- WebP に変換してからアップロードする。

---

## 7. アプリへの導線（記事末に必ず設置）

```
> 💸 契約中のサブスクを一覧にすると、判断はぐっと楽になります。
> 「やめどきAI Money」なら、金額と使用頻度から見直し候補を自動で並べてくれます。
> → [アプリを開く](https://…)
```

売り込まない。**「並べると楽になる」という事実だけ**を伝えること。

---

## 8. 執筆後のセルフレビュー（5問）

1. h2 だけ読んで、記事の内容が分かるか？
2. 数字は「月額」と「年額」の両方あるか？
3. 読者を責める表現・煽り表現はないか？（`brand.md`）
4. 次に読む記事へのリンクが 1〜2本あるか？
5. スマホで見て、4行以上続く段落がないか？

すべて Yes になったら `docs/seo-checklist.md` へ進む。
