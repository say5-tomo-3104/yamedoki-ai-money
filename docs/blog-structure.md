# blog-structure.md — WordPress サイト構成

「プロっぽく見える」の正体は、デザインより **構造の一貫性** です。
記事を1本書く前に、この設計に沿って器を整えてください。

---

## 1. サイトの全体像

```
トップページ（固定ページ・LP型）
├─ カテゴリ 1：サブスクを見直す      ← 主力。全記事の5割
├─ カテゴリ 2：サービス別ガイド      ← 検索流入の入口。3割
├─ カテゴリ 3：AI とお金             ← 差別化。1.5割
├─ カテゴリ 4：アプリの使い方        ← 既存ユーザー向け。0.5割
└─ 固定ページ群（About / お問い合わせ / プライバシーポリシー / 免責事項 / 運営者情報）
```

**鉄則：カテゴリは4つまで。** 増やしたくなったらタグで処理する。
カテゴリが多いサイトは、それだけで素人っぽく見えます。

---

## 2. カテゴリ設計

| カテゴリ | スラッグ | 扱う内容 | 記事例 |
|---|---|---|---|
| サブスクを見直す | `review` | 判断基準・考え方・家計全体 | 「サブスクの"やめどき"を決める3つの質問」 |
| サービス別ガイド | `services` | 個別サービスの料金・解約・代替 | 「U-NEXT は高い？ 月2,189円の元を取る条件」 |
| AI とお金 | `ai-money` | AI ツールの課金、AI での家計管理 | 「ChatGPT と Claude、両方契約する意味はあるか」 |
| アプリの使い方 | `app` | やめどきAI Money の使い方・更新情報 | 「見直しスコアの読み方」 |

### タグの運用
タグは **サービス名** と **金額帯** のみに限定する。

- サービス名タグ：`Netflix` `Spotify` `ChatGPT` …
- 金額帯タグ：`500円以下` `1000円台` `3000円以上`

感想や気分（`おすすめ` `まとめ` など）をタグにしないこと。増えて崩壊します。

---

## 3. パーマリンク（URL）

WordPress 設定 → パーマリンク → **カスタム構造**：

```
/%category%/%postname%/
```

- スラッグは**必ず英数字の手動入力**。日本語スラッグは URL がエンコードされて
  SNS で崩れるため禁止。
- 例：`/services/u-next-price/` `/review/subscription-timing/`
- 一度公開した URL は変えない。変える場合は必ず 301 リダイレクトを設定する。

---

## 4. トップページの構成（上から順に）

1. **ヒーロー**：タグライン「毎月の"なんとなく払い"を、いっしょに見直しましょう。」＋ アプリへの導線ボタン
2. **3つの数字**：「登録数」「今月合計」など、アプリのダッシュボードを想起させる要素
3. **はじめての方はこちら**：入門3記事へのカード（＝ピラーページ）
4. **新着記事**：6件
5. **カテゴリから探す**：4カテゴリのカード
6. **運営者について**：1段落 ＋ About ページへのリンク

トップに「最新記事の羅列」だけを置かないこと。それがいちばん素人に見えます。

---

## 5. 必須の固定ページ

| ページ | スラッグ | 必須理由 |
|---|---|---|
| このサイトについて | `about` | 信頼性。何者が何のために書いているか |
| 運営者情報 | `profile` | E-E-A-T。実名でなくても、経歴と発信理由を書く |
| お問い合わせ | `contact` | 広告審査・企業連絡で必須 |
| プライバシーポリシー | `privacy` | アクセス解析・広告を使うなら法的に必要 |
| 免責事項 | `disclaimer` | 金額情報を扱うため必須 |

免責事項には最低限これを書く：
> 本サイトの料金・プラン情報は執筆時点のものです。最新の情報は各サービスの公式サイトをご確認ください。
> 本サイトは特定の金融商品・投資を推奨するものではありません。

## 6. 内部リンクの設計（ピラー & クラスター）

```
ピラー記事：「サブスク見直しの完全ガイド」（カテゴリ: review）
  ├─ クラスター：Netflix の見直し方（services）
  ├─ クラスター：Spotify の見直し方（services）
  ├─ クラスター：AI ツール課金の考え方（ai-money）
  └─ クラスター：見直しスコアの読み方（app）
```

ルール：
- クラスター記事からは**必ずピラー記事へ1本**リンクする。
- ピラー記事からは**すべてのクラスター記事へ**リンクする。
- 関連しない記事同士は無理につながない。
- 各記事の最後に、次に読むべき記事を **1〜2本だけ** 提示する（多いと選ばれない）。

## 7. WordPress の推奨設定

### テーマ
シンプルな国産テーマ（SWELL / SANGO / Cocoon など）を1つ選び、
`brand.md` のカラーパレットをカスタマイザーに登録する。
**テーマを頻繁に変えないこと。** 一貫性が積み上がりません。

### 最低限入れるプラグイン
| 目的 | プラグイン例 |
|---|---|
| SEO | SEO SIMPLE PACK もしくは Yoast SEO |
| 目次 | Easy Table of Contents（h2/h3 で自動生成） |
| 画像最適化 | EWWW Image Optimizer（WebP 変換） |
| セキュリティ | SiteGuard WP Plugin |
| バックアップ | UpdraftPlus |
| お問い合わせ | Contact Form 7 |

**入れすぎない。** プラグインは10個以内を目安に。表示速度が落ちると全部が台無しです。

### 表示設定
- 1ページの表示件数：10件
- 抜粋表示（全文表示にしない）
- サイドバー：プロフィール → 人気記事 → カテゴリ → 検索 の順。広告を上に置かない。

---

## 8. 整理するときの手順（既存記事がある場合）

1. **棚卸し**：全記事を「URL / タイトル / カテゴリ / 文字数 / 最終更新日」で一覧化する。
2. **仕分け**：
   - 残す（上位カテゴリに再分類）
   - 統合する（似た内容の薄い記事は1本にまとめ、旧 URL は 301 リダイレクト）
   - 削除する（価値がなく検索流入もない記事は削除し、410 か関連記事へ 301）
3. **リライト**：残した記事を `docs/article-template.md` の型に直す。
4. **アイキャッチの統一**：`brand.md` のルールで全記事分を作り直す。ここで一気にプロっぽくなる。
5. **内部リンクの再配線**：ピラー & クラスターを組み直す。

一度に全部やらず、**アクセスの多い順に10本ずつ**進めること。
